# PROJETO-COMPUTACIONAL-REFERENTE-DISCIPLINA-DE-AN-LISE-EXPLORAT-RIA-DE-DADOS---25.1

Este relatório é uma análise exploratória de dados feita em R utilizando a base de dados ‘spotify-2023.csv’, cujo objetivo é investigar as características das músicas que foram mais reproduzidas no ano de 2023. A análise procura explicitar os padrões e as relações entre o sucesso das faixas em diferentes plataformas de streaming de música (Spotify, Apple Music e Deezer) e os atributos/características musicais - como bpm, dançabilidade, energia, valência e acusticidade. Esta pesquisa, como um todo, procura entender se técnicas musicais específicas auxiliam para o sucesso das faixas musicais ou se fatores externos, como, por exemplo, promoções e tendências culturais, possuem um forte papel no que torna uma música de fato popular. Além disso, a análise também trabalha com os dados faltantes, de tal forma que os exclui para garantir uma melhor avaliação dos dados como totalidade. Como resultado do relatório, destacam-se as correlações entre streams e as características musicais.
